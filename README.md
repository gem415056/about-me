# ABOUT ME

나를 깊이 이해하는 두 가지 여정: 심리학과 명리학 기반 심층 분석 대화형 웹 애플리케이션 및 사용자 맞춤 프롬프트 대화 스튜디오

## 핵심 기능

1. **심리학 세션 (Psychology Portal)**
   - 온보딩 톤/호칭/사유 맞춤 설정
   - 대화형 상황 질의(선택지)와 8대 심리 검사(에니어그램, DISC, MBTI, 빅파이브 등)
   - 3열 입체 에니어그램 레이더 차트, 대칭 게이지바 등 정밀 시각화
   - 전체화면 심층 분석 보고서 뷰어

2. **명리학 세션 (Saju Portal)**
   - 만세력(YAML) 및 사주 명식 프로필 등록·관리·선택 첨부
   - 멀티모달 파일(사진, TXT, HTML) 첨부 및 100% 무손실 보존
   - 무삭제 턴 교차 보정 및 안전한 토큰 슬라이싱 제어

3. **맞춤 프롬프트 대화 모드 (Custom Prompt Studio)**
   - 좌측 서랍 최하단 좌측 독립 `message-circle` 아이콘을 통한 새 탭 분리 실행
   - 상단 헤더의 `ABOUT ME` 로고 클릭 시 언제든 메인 천체 홈으로 복귀
   - 10종 인터랙티브 홈 화면 디자인 테스터 (모노리스 천체 오브, 에테르 카드 스와이퍼, 선 타이포그래피, 성운 나침반, 스튜디오 타일 등)
   - 우측 서랍 `file-cog` 아이콘: '프롬프트 설정' (추가, 삭제, 500ms 롱프레스 수정)
   - 프롬프트 선택 시 텍스트 칩 없이 은은한 세이지/말차 톤과 소프트 글로우 효과로만 표현
   - 선택된 커스텀 프롬프트를 Gemini API의 `systemInstruction`으로 직관적 주입

4. **데이터 영속성 및 클라우드 백업**
   - 브라우저 로컬 IndexedDB (`AboutMeDB`)를 통한 완벽한 개인정보 보호
   - JSON 파일 및 Firestore 기반 전체 데이터(심리/명리/맞춤 대화 기록 + 커스텀 프롬프트 전체) 원클릭 백업 및 복원

## 기술 스택
- **프론트엔드**: React 19, TypeScript, Vite
- **백엔드/API 프록시**: Node.js, Express, TSX
- **스타일링**: 순수 시맨틱 CSS (세이지·말차·오트밀 천체 테마)
- **AI 엔진**: Google Gemini API (SSE 스트리밍, 멀티모달, System Instruction 주입)
