# 인용구·문단 내 복수 줄(엔터 포함) 볼드 지원 및 불릿 텍스트 컬럼 쪼개짐 방지 계획서 (개정본)

인용구(`>`)나 문단 내에서 엔터(줄바꿈)로 떨어져 있는 텍스트(`>**줄1\n줄2**`)도 온전히 볼드 하이라이트로 감싸지도록 지원하고, 동시에 불릿 항목 간에는 태그가 교차 누수되어 텍스트가 여러 세로 열로 쪼개지는 결함을 방어하는 정밀 마크다운 파서 구현 계획서입니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> **사용자의 추가 요구사항 적극 반영**:
> - 사용자가 명시하신 **`>**블라블라\n블라블라**`**와 같이 **엔터로 줄이 바뀌어도 볼드가 끊기지 않고 전체 텍스트가 하나로 묶여 볼드 처리**되도록 지원합니다.
> - 기존 인용구 파서가 각 줄을 개별로 잘라 `parseInline`을 돌리는 바람에 복수 줄 볼드가 풀렸던 원인을 완벽히 해결합니다.
> - 단, 서로 다른 불릿 항목(`- 불릿1`과 `- 불릿2`) 사이로 볼드가 잘못 새어나가 HTML이 깨지는 현상은 불릿 단위 격리(Item Isolation)를 통해 철저히 방지합니다.

- **확정된 결정 1 (인용구 및 문단 내 복수 줄 볼드 지원)**:
  - 인용구(`>`) 블록 전체를 합친 문자열 단위에서 볼드(`**...**`)를 파싱하여, 인용구 안에서 여러 줄에 걸쳐 작성된 강조 문구가 온전히 하나로 볼드 처리되도록 구현합니다.
  - 일반 문단에서도 엔터로 이어진 복수 줄 볼드가 자연스럽게 매칭되도록 지원합니다.
- **확정된 결정 2 (불릿 항목 간 격리 - Item Isolation)**:
  - 불릿 목록(`- `, `* `)은 먼저 개별 불릿 항목 단위로 분리한 후, 각 불릿 항목 내부에서 복수 줄 볼드 및 인라인 서식을 적용합니다.
  - 이렇게 하면 불릿 1의 미완성 기호가 불릿 2로 침범하지 않아, 스크린샷처럼 텍스트가 여러 세로 열로 쪼개지는 현상이 원천 차단됩니다.
- **확정된 결정 3 (CSS 레이아웃 안전망 유지)**:
  - `.md-bullet-item`의 본문 컨테이너(`.md-sub-bullet-text`)에 `display: block !important; width: 100% !important; min-width: 0 !important;`를 적용하여 어떠한 상황에서도 텍스트가 단일 블록으로만 유려하게 흐르도록 보호합니다.

## 1. Overview & Core Concept

- **What It Does**:
  - `>**첫째 줄\n둘째 줄**`처럼 줄바꿈이 있는 인용구 및 본문 강조가 시각적으로 미려한 단일 볼드 블록으로 온전히 표현됩니다.
  - 불릿 항목의 텍스트는 가로 분할 없이 하나의 온전한 문단으로 넓게 펼쳐져 모바일 화면에서도 편안한 가독성을 제공합니다.
- **Key Value**:
  - AI가 생성하는 자유로운 줄바꿈의 강조 문구를 100% 누락 없이 표현하면서도 화면 레이아웃이 붕괴되지 않는 견고한 파싱 엔진 구축.

---

## 2. User Experience & Visual Design

- **인용구 복수 줄 볼드 예시**:
  ```markdown
  > **인월 정화는 목이 왕성하여
  반드시 경금으로 쪼개어야 한다.**
  ```
  - *결과*: 인용구 박스 안에서 두 줄 전체가 말차 톤의 웜 볼드 하이라이트로 유려하게 강조됨.
- **불릿 목록 예시**:
  ```markdown
  - 남성의 원국을 보십시오. 단 한 글자도 없습니다.
  - 남성은 뇌 속에 거대한 지식... **'날카로운 결단(金)'**이 없어...
  ```
  - *결과*: 불릿 기호 옆에 전체 문장이 하나의 넓은 문단으로 흐르며, 가로로 5개 열로 쪼개지는 글자 깨짐이 완전히 사라짐.

## 3. Technical Architecture & Parsing Strategy

### 파싱 순서 및 격리 아키텍처

```
┌────────────────────────────────────────────────────────┐
│                   AI Raw Markdown Text                 │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│             1. 블록 구조 분리 (Block Separation)       │
│  - 인용구 (> ...) 블록 통째로 추출                     │
│  - 불릿 목록 (- ...) 항목별로 분리                      │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│        2. 블록 내부 인라인 파싱 (Scoped Inline)         │
│  - 인용구 내부: 줄바꿈 허용 볼드 (복수 줄 지원)         │
│  - 불릿 항목 내부: 항목 안에서만 볼드 처리 (교차 누수 차단)│
│  - 일반 문단: 문단 안에서 줄바꿈 허용 볼드 처리        │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│             3. CSS Layout Defensive Shield             │
│  - .md-bullet-item: flex-row (아이콘 + 본문)           │
│  - .md-sub-bullet-text: display: block (단일 블록)      │
└────────────────────────────────────────────────────────┘
```

### 세부 코드 작업 항목

1. **`js/app.js` - `MarkdownParser.parseInline(text, allowMultiLine = true)`**:
   - `**([\s\S]+?)**` 패턴을 지원하되, 적용 대상 범위를 **동일한 블록(인용구 내부, 개별 불릿 내부, 단일 문단 내부)**으로 한정하여 줄바꿈 볼드를 온전히 지원하면서 불릿 간 누수를 방지.
2. **`js/app.js` - 인용구(`blockquote`) 파서 개선**:
   - 각 줄을 따로 돌리지 않고, 인용구 본문 전체 텍스트에 대해 `parseInline`을 실행한 뒤 줄바꿈을 조립하여 `>**줄1\n줄2**`가 통째로 볼드 처리되도록 수정.
3. **`js/app.js` - `parseLists` 개선**:
   - 불릿 항목(`item`) 텍스트에 대해 항목별로 `parseInline`을 호출하여 불릿 1의 기호가 불릿 2를 훼손하지 않도록 안전 격리.
4. **`style.css` - 레이아웃 방어 스타일 보강**:
   - `.md-sub-bullet-text`에 단일 블록 및 텍스트 래핑 속성을 명시하여 다열 쪼개짐 원천 방어.
