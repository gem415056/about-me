# 맞춤형 프롬프트 대화 모드 및 10종 인터랙티브 홈 디자인 테스팅 구현 계획서 (개정본)

좌측 서랍 최하단 좌측에 독립 배치된 `message-circle` 아이콘을 통해 진입하는 **새 탭 분리형 [맞춤 프롬프트 대화 모드]**를 구축하고, 사용자가 직접 눈으로 체험하며 최적의 홈을 선택할 수 있는 **10종 인터랙티브 홈 화면 디자인 테스팅 쇼케이스**를 구현합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **확정된 요구사항 및 핵심 의사결정 (피드백 반영 완료)**
> 1. **프롬프트 선택 상태 표현 (텍스트 칩 제거)**:
>    - 우측 서랍에서 프롬프트가 선택되었을 때 '선택됨' 같은 텍스트 칩이나 뱃지를 일체 사용하지 않습니다.
>    - 카드 자체의 **색상 전환(우아한 세이지·말차 틴트 배경)**, **1.5px 정교한 세이지 테두리**, 그리고 **은은한 소프트 글로우 섀도우 효과**만으로 세련되게 활성 상태를 표현합니다.
> 2. **진입 방식 (새 탭 분리 실행)**:
>    - 좌측 서랍 최하단 기존 우측 정렬 툴바와 구분되는 **독립된 좌측 정렬 영역**에 `message-circle` 아이콘 버튼을 배치하며, 클릭 시 새 탭(`?mode=custom` 또는 독립 라우트)으로 실행됩니다.
> 3. **헤더 홈 복귀**:
>    - 새 탭 모드에서도 상단 헤더의 `ABOUT ME` 로고를 클릭하면 즉시 기존 심리/명리학 메인 천체 홈(`landing`)으로 원활하게 복귀합니다.
> 4. **10가지 인터랙티브 홈 디자인 테스팅 페이지**:
>    - 10가지 개별 디자인 안을 실시간으로 전환하며 직접 클릭/인터랙션해보고 최종안을 고를 수 있는 **테스팅 셀렉터**를 인터랙티브하게 제공합니다.
> 5. **우측 서랍 [프롬프트 설정]**:
>    - 상단 우측 손(hand) 아이콘 대신 지정된 **`file-cog` SVG 아이콘** 적용.
>    - 우측 서랍 타이틀: **'프롬프트 설정'**.
>    - 프롬프트 추가(팝업창에서 제목/내용 입력), 선택 삭제, **길게 누르기(Long Press 500ms) 또는 우측 연필 버튼을 통한 수정** 지원.
> 6. **AI 전송 및 시스템 프롬프트 주입**:
>    - 선택된 맞춤 프롬프트가 Gemini API 요청의 `systemInstruction` 자리에 100% 무결하게 직접 주입됩니다.
>    - 파일/사진 첨부, 텍스트 전송, 토큰 계산, 턴 교차 보정 및 마크다운 렌더러는 기존 심리명리학 규격과 동일하게 작동합니다.
> 7. **IndexedDB 및 통합 백업/복원**:
>    - `custom_prompts` 신규 오브젝트 스토어를 추가하여 커스텀 프롬프트를 영구 보관.
>    - 백업 및 복원(JSON 및 클라우드) 시 심리학/명리학뿐만 아니라 **일반 맞춤 대화 기록 전체와 커스텀 프롬프트 목록까지 100% 무손실 백업 및 복원**됩니다.

## 1. Overview & Core Concept

- **목적**: 기존의 심리학(8대 검사·보고서) 및 명리학(사주·만세력 분석) 외에, 사용자가 직접 정의한 페르소나 및 지침(시스템 프롬프트)을 바탕으로 무엇이든 심층 탐구할 수 있는 자유롭고 강력한 대화 공간을 제공합니다.
- **주요 가치**:
  - 기존 앱의 품격 있는 미니멀·오트밀·말차 톤앤매너 및 정교한 인터페이스를 그대로 유지.
  - 사용자가 10가지 시각적·동적 홈 화면 후보를 직접 테스트하고 취향에 맞는 경험을 즉시 결정 가능.
  - 프롬프트 템플릿의 손쉬운 등록, 수정(길게 누르기), 선택(순수 색상/글로우 효과) 및 백업 일원화.

## 2. User Experience & Visual Design

### A. 좌측 서랍 하단 툴바 레이아웃
- 기존 우측 정렬된 3개 버튼(설정, 클라우드 백업, 클라우드 복원)과 분리하여, 툴바 좌측 끝에 `message-circle` 아이콘을 독립 배치(`justify-content: space-between`).
- 툴바 좌측:
  ```html
  <button id="btn-open-custom-mode" class="toolbar-btn" title="맞춤 프롬프트 대화 모드 열기 (새 탭)">
    <svg ... class="lucide lucide-message-circle ...">...</svg>
  </button>
  ```
- 툴바 우측: 기존 설정, 백업, 복원 버튼 유지.

### B. 10종 인터랙티브 홈 화면 테스팅 쇼케이스
상단에 미니멀한 **디자인 테스터 바**(`Design Selector: 1 ~ 10번`)를 두어 10가지 인터랙션을 원클릭으로 전환 및 비교할 수 있도록 구성합니다:
1. **[Design 1] 모노리스 천체 오브 (Monolith Resonance)**: 신비로운 단일 천체 궤도와 호흡하는 단일 오브를 터치해 바로 대화를 시작하는 디자인.
2. **[Design 2] 프롬프트 카드 캐러셀 (Ether Swiper)**: 등록된 맞춤 프롬프트들이 세이지·오트밀 카드로 부드럽게 슬라이드되며, 원하는 카드를 터치해 즉시 대화를 여는 형태.
3. **[Design 3] 선(Zen) 타이포그래피 & 플로팅 알약**: 여백의 미를 극대화한 미니멀 명조 문구와 중앙의 세련된 플로팅 '새 대화 시작' 알약 버튼.
4. **[Design 4] 천체 성운 나침반 (Celestial Astrolabe)**: 정밀 앤틱 눈금 링과 나침반 축을 터치하여 심층 탐구 대화로 진입하는 디자인.
5. **[Design 5] 프롬프트 프리셋 그리드 (Studio Tiles)**: 최근 설정한 프롬프트들이 앤틱 타일로 정돈되어 보이고, 상단에 자유 대화 시작 버튼 배치.
6. **[Design 6] 공명 파동 링 (Resonance Ripple)**: 은은하게 펄스하는 동심원 파동 애니메이션과 함께 직관적인 시작 버튼 배치.
7. **[Design 7] 미니멀 엠프티 캔버스 (Zen Canvas)**: 로고와 깊이 있는 한 줄 문구만 중앙에 두고, 화면 하단에 바로 질문을 던질 수 있는 웰컴 바 제공.
8. **[Design 8] 아카이브 쇼케이스 피드 (Chronicle Feed)**: 등록된 프롬프트 목록과 최근 대화 기록이 매끄러운 세로 피드로 이어지는 디자인.
9. **[Design 9] 코스믹 아틀라스 (Cosmic Atlas)**: 별자리 가이드선 배경 위에 '새로운 여정 시작' 링 버튼이 플로팅된 디자인.
10. **[Design 10] 모던 스튜디오 런치패드 (Studio Launchpad)**: 현재 활성화된 시스템 프롬프트가 상단에 은은한 톤으로 표시되고, 큼직한 원형 런치 버튼이 위치한 작업실 형태.

*사용자가 마음에 드는 디자인 상단의 "이 디자인으로 적용" 버튼을 누르면 해당 디자인이 고정 저장됩니다.*

### C. 우측 서랍 [프롬프트 설정]
- 헤더 우측: `file-cog` SVG 아이콘 클릭 시 우측 서랍 오픈.
- 서랍 상단:
  - 타이틀: **프롬프트 설정**
  - 액션: `+` (프롬프트 추가 버튼), `선택 삭제` 토글 버튼
- 프롬프트 카드:
  - 제목, 내용 미리보기.
  - **선택된 상태 시 시각 효과 (텍스트 칩 ZERO)**:
    - 배경색: 은은하고 짙은 세이지 그린 틴트 (`rgba(116, 123, 97, 0.12)`)
    - 보더: 1.5px 정교한 올리브 세이지 테두리 (`#747B61`)
    - 그림자: 소프트 앰비언트 글로우 (`box-shadow: 0 2px 10px rgba(116, 123, 97, 0.15)`)
    - 텍스트 '선택됨' 칩은 완전 배제.
  - 카드 터치: 해당 프롬프트를 현재 대화의 **활성 시스템 프롬프트**로 즉시 지정.
  - **길게 누르기(Long Press 500ms) 또는 우측 연필 버튼**: 프롬프트 수정 팝업 노출.
- 프롬프트 추가/수정 모달:
  - 제목 입력 필드, 프롬프트 내용(시스템 지침) 멀티라인 텍스트에어리어, 저장/닫기 시 자동 저장.

### D. 좌측 서랍 [대화 기록]
- 심리학/명리학 구분 섹션 대신, 단일한 **'대화 기록'** 섹션으로 통합.
- 각 대화 항목 클릭 시 해당 대화 세션 로드.
- 다중 선택 삭제 모드 동일 지원.

## 3. Key Product Decisions & Trade-Offs

- **순수 색상/글로우 기반 선택 피드백**: '선택됨' 텍스트 칩을 배제함으로써 군더더기 없는 미니멀리즘과 카드 본연의 텍스트 가독성을 극대화.
- **새 탭 라우팅 방식**: URL 쿼리 파라미터 `?mode=custom`을 활용하여 브라우저의 새 탭 격리를 구현하면서도 기존 IndexedDB와 API 프록시를 100% 공유.
- **백업 무결성 보장**: `CloudBackupManager`에서 `custom_prompts` 및 `category: 'custom'` 세션까지 전량 덤프/복원 대상에 포함하여 기기 이동 시에도 완벽한 연속성 유지.

### 단계별 개발 계획
1. **IndexedDB 스키마 확장**: `custom_prompts` 스토어 추가 (`keyPath: 'id'`, `autoIncrement: true`).
2. **LeftDrawer 툴바 업데이트**: 최하단 좌측에 `message-circle` 아이콘 독립 정렬 배치 및 새 탭 오픈(`window.open('?mode=custom', '_blank')`) 핸들러 연결.
3. **새 탭 맞춤 모드 라우팅 및 상태 관리**: `?mode=custom` 진입 처리, 통합 '대화 기록' 세션 관리, 헤더 로고 클릭 시 메인 홈 복귀.
4. **10종 인터랙티브 홈 화면 컴포넌트 & 테스터 셀렉터 구축**: 10가지 디자인(모노리스 오브, 카드 스와이퍼, Zen 타이포, 성운 나침반, 스튜디오 타일 등) 구현 및 실시간 전환/선택 UI 탑재.
5. **우측 서랍 [프롬프트 설정] 및 모달 구현**: `file-cog` 아이콘, 프롬프트 CRUD, 롱프레스 감지, 그리고 텍스트 칩 없는 순수 색상/글로우 선택 효과 적용.
6. **AIEngine 연동**: 선택된 커스텀 프롬프트를 `systemInstruction`으로 주입하여 질의응답 스트리밍.
7. **CloudBackupManager 업데이트**: 커스텀 프롬프트 및 커스텀 대화 세션/메시지까지 100% 백업/복원 지원.
8. **컴파일 검증**: `compile_applet`을 통한 TypeScript 빌드 무결성 확인.
