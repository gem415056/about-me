# 순수 사용자 텍스트 전송 및 프롬프트 로딩 무결성 보장 계획

사용자의 명확한 요구사항 및 답변을 반영하여, 인위적으로 주입되던 기본 템플릿 문구를 전면 제거하고 오직 사용자가 직접 작성하거나 선택 조립한 순수 텍스트만 전송되도록 수정하며, 브라우저 샌드박스 환경에서 발생하던 "프롬프트 불러오지 못함" 오류를 근본적으로 해결합니다.

> [!IMPORTANT]
> **확정된 핵심 요구사항 (사용자 답변 반영)**
> 1. **기본 안내 템플릿 문구 전면 제거**: `"만세력을 바탕으로 사주를 분석해 주세요."`, `"첨부한 사진을 바탕으로..."`와 같은 인위적인 대체 문구를 코드 전역(`ChatManager.sendMessage`, `buildContents` 등)에서 완전히 삭제합니다.
> 2. **텍스트 필수 입력 제한**: 만세력이나 사진만 첨부하고 텍스트가 없는 상태에서는 전송되지 않도록 제한(텍스트 1자 이상 필수 입력)합니다.
> 3. **순수 사용자 발화 전송**:
>    - **명리학**: 사용자가 입력창에 직접 작성한 질문 텍스트 그대로 전송
>    - **심리학**: 온보딩 카드에서 사용자가 직접 선택 및 작성하여 조립된 페이로드(톤, 닉네임, 첫 이야기) 및 후속 질문 텍스트 그대로 전송
> 4. **"프롬프트 불러오지 못함" 오류 근본 해결**: 브라우저 iframe 샌드박스에서 `cache: 'no-store'` 모드 거부 또는 상대경로 불일치로 인해 발생하던 클라이언트 fetch 실패를 다각도로 복구하고, 서버 프록시(`/api/gemini`)가 디스크의 txt 파일을 실시간 보증하도록 직결합니다.

---

### User Review & Critical Decisions

- **결정 1 (인위적 템플릿 문구 완전 박멸)**:
  - 기존 코드에 남아있던 `defaultPrompt` 및 `|| '만세력을 바탕으로 사주를 분석해 주세요.'` 형태의 모든 인위적 대체 텍스트를 제거합니다.
  - 사용자가 작성하지 않은 텍스트가 AI 페이로드에 섞여 들어가는 일을 원천 차단합니다.
- **결정 2 (전송 유효성 검사 강화)**:
  - 사진이나 명식이 첨부되어 있더라도 텍스트 입력창이 비어있으면 전송되지 않도록 검사 조건을 `if (!text) return;`으로 강화합니다.
  - 플레이스홀더나 툴팁으로 사용자가 질문을 입력하도록 유도합니다.
- **결정 3 (프롬프트 로딩 복원력 극대화 & 서버 직결)**:
  - 브라우저 환경에서 `fetch`에 `cache: 'no-store'` 옵션을 주면 일부 샌드박스 iframe 환경에서 보안 정책으로 인해 요청 자체가 차단되는 현상을 방지하기 위해, 타임스탬프 쿼리(`?t=Date.now()`) 기반 무캐시 방식으로 전환합니다.
  - 상대 경로(`api/prompt/${category}`, `prompt_${category}.txt`)와 절대 경로(`/api/prompt/${category}`, `/prompt_${category}.txt`)를 순차 시도하는 다중 안전 로더를 구성합니다.
  - 서버 프록시(`/api/gemini`)에서 `category` 수신 시 로컬 디스크(`fs.readFileSync`)에서 실시간으로 프롬프트를 보증하므로, 클라이언트 측에서 불필요하게 통신을 중단시키는 하드 에러를 방지하고 서버가 100% 원형 그대로 전달하도록 합니다.

### 1. Technical Architecture & Data Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                       사용자 입력 레이어                        │
│  - 명리학: 사용자가 직접 작성한 텍스트 (텍스트 미입력 시 전송 차단) │
│  - 심리학: 온보딩 선택/작성 조립 텍스트 또는 후속 입력 텍스트    │
│  ※ 인위적 기본 안내 템플릿 문구 완전 배제                      │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                 AIEngine.buildContents & sendRequest            │
│  - userText: 사용자 순수 입력값만 그대로 바인딩                  │
│  - 첨부 이미지: 순수 이미지 바이너리만 첨부 (이름 등 텍스트 배제)│
│  - systemInstruction: 안전한 무캐시 로딩 & category 전달         │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                 Node.js Server (/api/gemini)                    │
│  - 디스크의 prompt_saju.txt / prompt_psychology.txt 실시간 대조 │
│  - 사용자가 txt 파일 수정한 내용 100% 무결하게 페이로드 결합     │
└─────────────────────────────────────────────────────────────────┘
```

### 2. Implementation Steps

1. **`js/app.js` 템플릿 문구 전면 제거 및 전송 검증**:
   - `ChatManager.sendMessage`:
     - `const text = inputEl.value.trim();`
     - `if (!text) return;` (텍스트가 없으면 전송 차단)
     - 인위적인 `defaultPrompt` 생성 및 대체 코드 완전 삭제
   - `AIEngine.buildContents`:
     - 과거 턴 및 현재 턴의 `cleanContent || defaultPrompt` 대체 코드 삭제
     - 사용자가 보낸 순수 `cleanContent`와 `cleanUserText`만 전달
   - `ChatManager.sendChoicePayload`:
     - 심리학 온보딩에서 조립된 텍스트(`payloadText`)만 그대로 전달
2. **`js/app.js` 프롬프트 로딩 샌드박스 호환성 개선**:
   - `fetch` 호출 시 iframe 샌드박스를 깨뜨릴 수 있는 `cache: 'no-store'` 대신 `?t=${Date.now()}` 쿼리 파라미터를 사용하여 안전하게 캐시 우회.
   - 경로 탐색: `api/prompt/${category}`, `/api/prompt/${category}`, `prompt_${category}.txt`, `/prompt_${category}.txt` 순차 로드.
   - 서버 프록시(`/api/gemini`) 호출 시 `category`를 함께 전달하여, 서버가 디스크의 최신 txt 파일 원문을 직접 주입할 수 있도록 보장.
3. **`server.js` 프록시 및 디스크 직결 검증**:
   - `server.js`의 `/api/gemini`에서 `category`가 들어오면 디스크의 `prompt_${category}.txt`를 확실하게 읽어 `payload.systemInstruction`에 최종 주입.
4. **검증**:
   - 텍스트 없이 전송 시도 시 전송되지 않는지 확인.
   - 명리학 대화방에서 텍스트 입력 및 만세력 첨부 후 전송 시 `prompt_saju.txt` 내용과 사용자 텍스트만 전달되는지 확인.
   - 심리학 대화방에서 온보딩 카드 제출 시 조립된 텍스트와 `prompt_psychology.txt`가 전달되는지 확인.
   - `compile_applet` 및 `lint_applet` 실행.
