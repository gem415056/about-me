# 실시간 토큰 모니터링 칩 및 커스텀 대화 슬라이싱 제어 구현 계획 (2차 개정)

대화 중 소모되는 토큰 규모를 실시간으로 직접 확인하고, 필요 시 대화 텍스트에 한해 원하는 토큰 수만큼 슬라이싱할 수 있는 직관적인 UI 및 페이로드 제어 기능을 구축합니다.

---

### 사용자 검토 및 핵심 결정 사항

> [!IMPORTANT]
> - **기본 권장 토큰 기준 (50,000 토큰)**: 사용자의 충분하고 깊이 있는 대화 턴을 보장하기 위해 기본 권장 토큰을 **50,000 토큰**으로 설정합니다.
> - **알약 칩 표시 모드 전환**:
>   - **슬라이싱 OFF**: `현재토큰 / 50000` (기본 권장 토큰) 표시.
>   - **슬라이싱 ON**: `현재토큰 / [사용자가 설정한 슬라이싱 토큰]` (예: `18200 / 40000`)으로 분모 숫자가 실시간 전환.
> - **단일 고정 색상 유지 (색상 변경 일체 금지)**: 슬라이싱 OFF 상태에서 50,000 토큰을 초과하더라도 경고색(빨강, 주황 등)으로 바뀌지 않으며, 언제나 단정하고 은은한 단일 톤을 유지합니다.
> - **기본 전송 정책 (무삭제 원칙)**: 슬라이싱 토글을 켜지 않은 상태에서는 토큰 수가 초과하더라도 **임의 삭제나 축약 없이 모든 대화가 100% 원본 그대로 전송**됩니다.
> - **대화 순서 무삭제 보전**: API 교차 규격(`user ↔ model`) 유지를 위해 대화를 임의 삭제하지 않고, 불완전한 턴이 있을 경우 점(`.`)이나 공백을 보충하여 모든 턴을 보존합니다.
> - **에러 안내 정리**: 불필요한 인라인 [다시 시도] 버튼을 제거하고, 기존 말풍선 하단 리롤(새로고침) 버튼과 연계하여 깔끔한 에러 안내만 유지합니다.

### 1. 개요 및 주요 기능

1. **실시간 토큰 플로팅 알약 칩**:
   - 상단 헤더 바로 아래 우측에 약간 반투명한 화이트 알약(Pill) 형태의 칩 배치.
   - 텍스트 없이 숫자만 표기: `14250 / 50000` (슬라이싱 ON 시 `14250 / 입력한토큰수`).
   - 초과 여부와 무관하게 동일한 세련된 반투명 디자인 유지 (색상 변화 없음).
   - 대화가 진행되거나 메시지를 입력/삭제/수정할 때 실시간으로 자동 갱신.
2. **토큰 슬라이싱 설정 팝업 (서랍 설정 팝업 디자인 일치)**:
   - 플로팅 칩 클릭 시 왼쪽 서랍의 [설정] 팝업과 동일한 말차/아이보리 톤의 모달 창 오픈.
   - **토큰 슬라이싱 활성화 토글 스위치**:
     - 기본값: OFF (초과하더라도 모든 대화 원문 전송, 칩에는 `/ 50000` 표시).
     - ON 전환 시: 하단에 슬라이싱 기준 토큰을 입력할 수 있는 입력창이 부드럽게 노출(Reveal)되며, 칩의 분모 숫자가 입력한 토큰 값으로 즉시 연동.
3. **대화 전용 슬라이싱 엔진**:
   - 슬라이싱 토글이 ON이고 총 토큰이 지정 한도를 초과할 때만 동작.
   - **사진, 만세력 이미지, 첨부 문서는 100% 무손실 원본 그대로 보존 전송**.
   - 대화 내역 중 가장 오래된 텍스트 턴부터 순차적으로 축약하여 지정 토큰 수 이내로 조절 (최근 대화와 현재 질문 우선 보존).

### 2. 사용자 경험 (UX) 및 시각 디자인

- **플로팅 알약 칩 디자인**:
  - 위치: 채팅 화면 상단 헤더 바로 아래 우측 (`position: absolute; top: 62px; right: 16px; z-index: 40;`)
  - 스타일: 반투명 화이트 배경 (`background: rgba(255, 255, 255, 0.78); backdrop-filter: blur(8px);`), 은은한 테두리 (`border: 1px solid rgba(0, 0, 0, 0.08);`), 알약 둥근 형태 (`border-radius: 9999px;`), 폰트(`font-size: 0.78rem; font-weight: 600; color: #4B533C; font-variant-numeric: tabular-nums;`).
  - 토큰 초과 시에도 텍스트 색상 및 배경 색상 변경 없이 일관된 스타일 고정.
- **슬라이싱 설정 팝업 모달**:
  - 서랍 메뉴의 설정 창(클린 카드, 스위치 토글, 둥근 모서리, 폰트 규격)과 100% 동일한 디자인 시스템 준수.
  - 헤더: "대화 맥락 및 토큰 설정" + ✕ 닫기 버튼.
  - 설명: "기본 권장 토큰(50,000)을 초과해도 모든 대화가 전송됩니다. 대화 맥락을 조절하려면 슬라이싱을 활성화하세요."
  - 스위치: [대화 토큰 슬라이싱 제한 사용] (ON / OFF).
  - 조건부 입력창: 슬라이싱 최대 토큰 수 입력 (기본 입력 플레이스홀더: `50000`), 단위 레이블 표기.

### 3. 시스템 아키텍처 및 데이터 흐름

```
┌────────────────────────────────────────────────────────┐
│  헤더 아래 우측: 플로팅 알약 칩                         │
│  [ 현재토큰 / 50000 ]  (슬라이싱 OFF 시)                │
│  [ 현재토큰 / 40000 ]  (슬라이싱 ON 및 40000 입력 시)   │
└───────────────────────────┬────────────────────────────┘
                            │ (클릭 시)
                            ▼
┌────────────────────────────────────────────────────────┐
│  토큰 제어 모달 (서랍 설정 팝업 디자인)                 │
│  ├─ 슬라이싱 토글: [ ON / OFF ]                        │
│  └─ (ON 시 노출) 최대 토큰 입력: [ 50000 ]             │
└───────────────────────────┬────────────────────────────┘
                            │ (설정 저장: DB 'settings')
                            ▼
┌────────────────────────────────────────────────────────┐
│  AIEngine.buildContents (페이로드 생성)                │
│  ├─ 1. 사진 / 파일 / 만세력: 100% 온전하게 주입 (무손실)│
│  ├─ 2. 슬라이싱 OFF: 과거 대화 100% 전송 (초과 무관)   │
│  ├─ 3. 슬라이싱 ON: 대화 텍스트만 오래된 순부터 컷팅   │
│  └─ 4. 교차 순서 보정: 삭제 없이 누락 턴에 '.' 보충   │
└────────────────────────────────────────────────────────┘
```

### 4. 구현 상세 계획

1. **에러 말풍선 정리 및 무삭제 보완 (`js/app.js`)**:
   - `onError`에서 `[다시 시도 (Retry)]` 버튼 DOM 생성 코드 제거 (리롤 버튼으로 충분).
   - 대화 턴 교차 구조 검증 시, 사용자 대화가 연속되거나 짝이 안 맞을 때 메시지를 삭제하지 않고 빈 응답(공백 또는 `.`)을 보충해 원본 사용자 기록을 100% 보존.
2. **토큰 계산기 및 실시간 갱신 함수 (`js/app.js`)**:
   - 한글(약 1.5~2토큰/글자), 영문/기호(약 0.25~0.5토큰/글자), 이미지(고정 토큰 약 258~1000)를 신속하게 추정 계산하는 `TokenEstimator` 모듈 추가.
   - 메시지 추가, 삭제, 세션 로드 시 플로팅 칩 숫자 실시간 업데이트.
   - 슬라이싱 토글 ON 여부에 따라 분모 숫자를 `50000` 또는 `설정된 슬라이싱 토큰값`으로 동적 렌더링.
   - 초과 시에도 색상 변동 없는 고정 스타일 적용.
3. **플로팅 칩 UI 및 이벤트 바인딩 (`index.html`, `js/app.js`)**:
   - 사주 및 심리학 뷰의 헤더 하단에 플로팅 칩 마운트.
   - 클릭 시 토큰 슬라이싱 설정 모달 팝업 호출.
4. **토큰 슬라이싱 설정 팝업 UI 및 저장 로직 (`js/app.js`)**:
   - IndexedDB `settings` 테이블의 `token_slicing_config` (`{ enabled: false, maxTokens: 50000 }`)과 연동.
   - 토글 전환에 따른 입력창 실시간 Show/Hide 애니메이션 및 칩 분모 즉시 갱신.
5. **페이로드 슬라이싱 처리 (`AIEngine.buildContents`)**:
   - 슬라이싱 옵션이 켜져 있는 경우, 첨부파일을 제외한 순수 텍스트 대화 히스토리에서만 역순으로 누적 토큰을 계산하여 오래된 턴을 안전하게 분리.

### 5. 검증 계획

1. **빌드 및 린트 검증**: `npm run lint` 통과 확인.
2. **플로팅 칩 확인**:
   - 슬라이싱 OFF 시: `현재토큰 / 50000` 표시 확인.
   - 슬라이싱 ON 시: `현재토큰 / [설정값]`으로 즉시 변경되는지 확인.
   - 50,000 초과 시에도 글자 색상 등이 빨갛게 변하지 않고 기존 단정한 스타일이 유지되는지 확인.
3. **모달 팝업 확인**: 칩 클릭 시 서랍 메뉴 설정 창과 동일한 스타일로 모달이 열리고, 토글에 따라 입력창이 나타나고 숨겨지는지 확인.
4. **전송 검증**:
   - 토글 OFF 시: 토큰 수가 50,000을 넘어도 모든 대화가 전부 전송되는지 확인.
   - 토글 ON 시: 사진과 첨부파일은 100% 유지되고, 대화 텍스트만 지정된 토큰 이내로 깔끔하게 맞춰 전송되는지 확인.
