# 마크다운 파서 파싱 순서 조절 및 불릿·인라인 서식 스마트 묶음 개선 계획서

불릿 목록(`- `, `* `, 번호 목록) 내에 볼드(`**`), 이탤릭, 링크 등의 인라인 서식이 포함되어 있을 때 모바일 화면에서 문장이 여러 세로 열(컬럼)로 쪼개지거나 단어가 세로로 길게 늘어지는 결함을 해결합니다. 사용자 피드백을 100% 반영하여 기존 스타일 감성은 온전히 유지하되, 파싱 순서를 지능적으로 재배치하고 불릿 항목을 안전한 단일 블록으로 묶어 내부 인라인 서식이 자연스럽게 흐르도록 구현합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> **사용자 답변 및 핵심 지침 반영**:
> - **레이아웃 유지 & 스마트한 묶음**: 기존의 디자인 톤(오가닉 말차 테마, 미니멀 대시 불릿)은 그대로 유지하며, 불릿 항목 묶음과 파싱 순서를 스마트하게 교정합니다.
> - **불릿 단일 흐름 보장**: 불릿으로 묶인 항목은 온전한 하나의 문단/블록으로 표시되고, 그 내부의 인라인 볼드(`**...**`)나 강조 서식은 텍스트 흐름을 깨뜨리지 않고 인라인 서식으로만 정돈되도록 파싱 순서 및 컨테이너를 정립합니다.
> - **기호 짝 판정 보존**: 별표나 따옴표 짝 어긋남 로직을 임의로 건드리지 않고, 파싱 파이프라인의 구조적 격리와 순서 재배치로 원인을 근본 해결합니다.

- **확정된 결정 1 (파싱 파이프라인 순서 재배치 & 블록 보호)**:
  - 기존 테이블(`parseMarkdownTable`), 인용구(`blockquote`), 코드블록처럼 불릿 목록(`parseLists`) 역시 파싱 완료 즉시 `saveBlock` 플레이스홀더로 완벽히 보호하여 후속 단락(`p`) 분할 및 인라인 파싱 단계에서 HTML 태그가 오염되거나 재분할되지 않도록 합니다.
- **확정된 결정 2 (불릿 본문 컨테이너 시맨틱 및 CSS 방어막 강화)**:
  - `<div class="md-bullet-item">` 내 본문 영역을 `span` 대신 정식 블록 컨테이너인 `<div class="md-bullet-content">`로 구성하고, `flex: 1 1 auto; min-width: 0; display: block; word-break: break-word;`를 적용하여 브라우저 flex formatting context에서 자식 텍스트 노드와 볼드 span들이 별도 flex item 컬럼으로 분리되는 현상을 원천 방지합니다.
- **확정된 결정 3 (인라인 서식 스코프 격리)**:
  - 각 불릿 항목의 본문 텍스트 내에서 인라인 볼드/서식을 독립적으로 치환한 후 블록을 조립하므로, 불릿 항목 간에 서식 누출이나 태그 엉킴이 발생하지 않습니다.

## 1. Overview & Core Concept

- **What It Does**:
  - 사주 명리학 및 심리학 대화창에서 AI가 전송한 불릿 목록(`- **해동(解凍) 속도의 차이:** 여성은 ... **여성이 훨씬 빠르고 격렬**하게 일어납니다.`)이 가로 4~5개 세로 열로 쪼개지지 않고, 하나의 유려하고 정돈된 문장 블록으로 렌더링됩니다.
  - 불릿 항목의 제목 볼드나 본문 중간의 볼드가 문장 흐름 안에 자연스럽게 녹아들어 모바일(삼성 브라우저, 사파리, 크롬) 화면에서 편안한 가독성을 제공합니다.
- **Key Value**:
  - 화면 깨짐 없는 견고한 텍스트 렌더링 보장.
  - 기존 UI/UX 및 디자인 스타일의 100% 무손실 계승.

## 2. Technical Architecture & Parsing Pipeline

### 마크다운 파싱 순서 개선도

```
┌────────────────────────────────────────────────────────┐
│                   AI Raw Markdown Text                 │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│  Step 1: 특수 블록 추출 & saveBlock 보호                │
│  - JSON 게이지 블록 (isReport)                         │
│  - 코드 블록 (```code```)                              │
│  - 마크다운 테이블 (| col | col |)                     │
│  - 헤더 7단계 (# ~ #######)                            │
│  - 인용구 (> ...)                                      │
│  - 구분선 (---)                                        │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│  Step 2: 목록(List) 스마트 파싱 & saveBlock 보호 [핵심]│
│  - 번호 목록 및 하위 서브 불릿 추출                   │
│  - 순수 불릿 목록 (- , * , •) 다계층 파싱              │
│  - 각 불릿 항목 단위로 본문 인라인 서식 적용          │
│  - <div class="md-bullet-content"> 블록으로 묶기       │
│  - 결과 그룹을 saveBlock 플레이스홀더로 즉시 보호!     │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│  Step 3: 일반 단락(<p>) 및 여백 처리                   │
│  - \n{2,} 분할 및 일반 문단 인라인 파싱               │
│  - 보호된 블록(saveBlock)은 일체 훼손 없이 통과        │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│  Step 4: saveBlock 원본 복원 & 최종 DOM 렌더링        │
│  - 보호된 불릿, 인용구, 테이블, 코드블록 일괄 복원     │
└────────────────────────────────────────────────────────┘
```

## 3. Key Implementation Details

1. **`js/app.js` - `MarkdownParser.parse` 파이프라인 개편**:
   - `this.parseLists(processed)` 결과를 `saveBlock` 플레이스홀더로 보호하도록 변경하여, 후속 `blocks = processed.split(/\n{2,}/)` 과정에서 불릿 그룹 내부가 쪼개지거나 추가 조작되지 않도록 방어.
   - 불릿 목록 내 본문 영역을 `<div class="md-bullet-content">`로 감싸 시맨틱 블록 레이아웃 보장.
2. **`style.css` - 불릿 아이템 및 본문 스타일 보강**:
   - `.md-bullet-content` 및 `.md-sub-bullet-text`에 `flex: 1 1 auto; min-width: 0; display: block; word-break: break-word;` 지정.
   - 내부의 인라인 요소(`.md-bold-highlight`, `.md-underline`, `strong`, `em` 등)가 독립 컬럼으로 분리되지 않고 텍스트 스트림 내에 머물도록 `display: inline;` 명시.
3. **무손실 검증**:
   - 사용자가 제공한 두 가지 실제 마크다운 샘플(사주 대화 인용구 + 불릿 목록, 4단계 헤더 + 다중 볼드 불릿 목록)을 node 및 jsdom 환경에서 자동 렌더링 검증.
